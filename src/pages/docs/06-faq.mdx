# Perguntas Frequentes

**P: Posso ter múltiplas anotações em uma única tarefa?** <br />
R: Não, cada tarefa possui espaço para um único bloco de anotações, porém você pode organizar suas anotações de forma a incluir informações detalhadas.

**P: Como baixar um arquivo com minhas tarefas?** <br />
R: Basta selecionar as tarefas e um botão para realizar a exportação vai aparecer ao lado do botão de adicionar tarefa.

**P: Existe um limite de texto nas anotações?** <br />
R: Não há limite prático para o texto que você pode adicionar nas anotações, mas tente ser breve para não se perder.
